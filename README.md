# 🏦 Bank Credit & Debit Dashboard  

An interactive **Tableau dashboard** designed to monitor and analyze bank credit and debit transactions across multiple branches.  
The dashboard provides insights into **transaction volumes, credit-debit ratios, risk flags, and monthly performance trends** for data-driven decision-making.  

---

## 🎯 Project Objective  

To visualize and compare **credit and debit transactions** across banks, branches, and transaction methods, helping financial teams track performance and identify anomalies.  

---

## 📊 Key Insights  

- 💰 **Total Credit Amount:** 128M | **Total Debit Amount:** 127M  
- 🔄 **Net Transaction Amount:** 318K | **Credit-Debit Ratio:** 1.00  
- ⚠️ **High-Risk Transactions:** 20.4K out of 100K total  
- 🏦 **Branch & Bank-Level Trends:** Highlights transaction growth and activity ratios  
- 💳 **Transaction Methods:** Comparison between Debit, Credit, and Bank Transfer usage  
- 📈 **Monthly & Quarterly Performance:** Tracks growth and seasonal fluctuations

## ⚙️ Workflow  

1. **Data Preparation:** Cleaned and structured transaction data in Excel.  
2. **Data Modeling:** Defined KPIs such as total credit, debit, and risk flags.  
3. **Visualization:** Designed interactive dashboard using Tableau sheets and filters.  
4. **Analysis:** Derived insights by comparing performance across branches and methods.
